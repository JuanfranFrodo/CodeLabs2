## 📝 Descripción

**CodeLabs2** agrupa las diferentes clases y ejercicios desarrollados en el entorno de aprendizaje. Incluye implementaciones en Programación Orientada a Objetos (POO), gestión de entrada/salida por consola con `Scanner`, estructuración de paquetes y controladores principales.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java (JDK 21+)
* **IDE:** IntelliJ IDEA
* **Control de versiones:** Git & GitHub
